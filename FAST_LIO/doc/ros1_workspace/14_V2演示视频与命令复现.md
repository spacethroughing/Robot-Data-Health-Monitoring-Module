## 启动 ROS 与正常 STOP/RUN

以下命令用于复现 managed bag 场景。先在终端 1 启动独立 master：

```bash
source /opt/ros/noetic/setup.bash
source $HOME/fastlio_ws/devel/setup.bash
export ROS_MASTER_URI=http://localhost:33498
roscore -p 33498
```

终端 2 启动 FAST-LIO、健康检测台和 RViz：

```bash
source /opt/ros/noetic/setup.bash
source $HOME/fastlio_ws/devel/setup.bash
export ROS_MASTER_URI=http://localhost:33498
roslaunch fastlio_health_monitor managed_bag_testbench.launch rviz:=true
```

终端 3 发送停止命令；观察 `STOPPED` 状态并保持至少 30 秒，再发起恢复：

```bash
source /opt/ros/noetic/setup.bash
source $HOME/fastlio_ws/devel/setup.bash
export ROS_MASTER_URI=http://localhost:33498
rosservice call /robot_runtime/control "{binding: 'localization', command: 'STOP'}"
```

```bash
rosservice call /robot_runtime/control "{binding: 'localization', command: 'RUN'}"
```

查看诊断状态可另开终端运行：

```bash
source /opt/ros/noetic/setup.bash
source $HOME/fastlio_ws/devel/setup.bash
export ROS_MASTER_URI=http://localhost:33498
rostopic echo /fastlio_health_monitor/diagnostics
```

测试中 STOP 命令返回 `accepted: True`，定位停止后稳定保持 30.649 秒，期间 IMU 持续输入且未产生停止误报；RUN 在 1.603 秒后达到 RUNNING，生产者实例 ID 更新，未出现跨实例跳变误报。终端 2 按 `Ctrl+C` 结束 launch，终端 1 按 `Ctrl+C` 结束 roscore。
