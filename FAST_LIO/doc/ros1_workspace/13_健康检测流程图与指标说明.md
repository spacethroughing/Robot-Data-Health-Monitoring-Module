# 健康检测流程图

更新日期：2026-10-14。总图展示主要处理顺序；具体规则和阈值以运行配置为准。

![机器人数据健康监控流程](images/health_v2_actual_monitoring_flow.png)

## 主流程

1. 启动时读取 YAML 配置。
2. 接收雷达、IMU 和定位数据，适配器统一消息格式、单位和坐标。
3. 分别检查三类数据；时间探针持续监测数据中断。
4. 按配置汇总为 OK、WARNING 或 ERROR。
5. 在 RViz 和 ROS 诊断中显示结果，并保存 JSONL 事件和 CSV 指标。

## 定位停止与重启

定位正常停止后，面板显示灰色待机，定位状态为不可用；雷达、IMU 和监控进程可以继续运行。重新启动定位后，监控建立新数据基线，不使用停止前的样本计算速度和加速度。状态变化见 [生命周期状态图](images/health_v2_lifecycle_flow.png)。

## 配置与时间概念

运行阈值位于 fastlio_health_monitor/config/health_v2_avia.yaml。改动参数后需要重新启动监控。仓库中的示例数值用于开发和回放，实际部署前应按设备和采样率调整。

- **时间戳：** 消息产生时记录的时间，用于检查顺序和源频率。
- **断流时长：** 当前时间距离最后一次接收消息的时间，用于及时发现无数据。
- **传输延迟：** 需要设备时间和主机时间可靠对应；未建立时钟对应关系时显示 N/A。
